# Управление серверным парком (DataCenter Manager)

Конфигурация для 1С:Предприятие 8.3. Учёт серверов в дата-центрах, управление ПО, назначение серверов клиентам.

## Возможности

- Учёт серверов с характеристиками (процессор, ОЗУ, диски, юниты)
- Учёт установленного программного обеспечения
- Назначение серверов клиентам и проектам
- Загрузка серверов из Excel
- Отчёты: паспорт сервера, загрузка стоек, распределение по целям

## Структура метаданных

### Подсистемы
- **НСИ** — справочники
- **УчётОборудования** — приёмка, инвентаризация, списание
- **УчётПО** — установка программного обеспечения
- **УчётНазначений** — назначение серверов клиентам

### Справочники
- Серверы
- Датацентры
- МоделиОборудования
- ПрограммноеОбеспечение
- Клиенты
- ПроектыКлиентов

### Документы
- ПриемкаСервера
- УстановкаПО
- НазначениеСервераКлиенту
- ИнвентаризацияСервера
- ВыводИзЭксплуатации

### Регистры
- ХарактеристикиСервера (сведения, периодический)
- УстановленноеПО (сведения, периодический)
- ИсторияНазначенийСерверов (накопления, оборотный)

### Отчёты
- Паспорт сервера (три набора данных, левые соединения)
- Загрузка стоек (вычисляемые поля, условное оформление)
- Распределение серверов по целям (круговая диаграмма)

### Обработки
- Загрузка серверов из Excel

## Установка

1. Создать пустую информационную базу
2. Загрузить конфигурацию из файла `.cf`
3. Обновить конфигурацию базы данных (F7)
4. Запустить 1С:Предприятие

## Тестовые данные

Заполнить справочники:
- Датацентры: Москва, Санкт-Петербург
- МоделиОборудования: 2-3 модели с характеристиками
- ПрограммноеОбеспечение: ОС, СУБД
- Серверы: 3-4 сервера

Или воспользоваться обработкой загрузки из Excel.

## Архитектурные решения

- Статусы серверов реализованы как перечисление для целостности данных
- Характеристики серверов хранятся в периодическом регистре для отслеживания апгрейдов
- ПО хранится отдельным регистром для независимого учёта
- Назначения клиентам — оборотный регистр для аналитики по периодам
